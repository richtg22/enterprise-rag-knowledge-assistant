# Enterprise RAG Knowledge Assistant

A full-stack RAG-based knowledge assistant that allows users to upload multiple PDF documents and ask grounded questions with source citations.

## Features

- Multi-PDF upload
- RAG-based question answering
- Source citations with page numbers
- Chat history
- Clear knowledge base
- Upload statistics
- React frontend
- FastAPI backend
- ChromaDB vector store
- Groq LLM integration

## Tech Stack

React, FastAPI, LangChain, ChromaDB, Groq, Python, JavaScript

## Current Status

Version 1 completed. Conversational memory will be added next.
